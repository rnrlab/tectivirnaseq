Obtain rho proportionality

Correlation shows how two variables vary together. In the case of RNAseq data, these correlations are inevitably relative, since we don’t have the total number of reads, but rather a proportion of the total. Although algorithms like WGCNA employ Pearson correlation, this can lead to spurious associations, and more recent advances, especially in metagenomics, suggest the use of compositionally-aware methods. One such method is the rho (ρ) statistic, which can be used instead of correlation as the basis for familiar analyses and visualization methods, including coexpression networks and clustered heatmaps. In this case, we used rho proportionality to measure coexpression among GBJ002 (chromosome and pBtic235) and GIL16 genes and GIL16 samples at time points 0, 10, 30 and 60, excluding 60-mock samples, since they are not induced by MMC and may introduce noise.

Code 
pseudocount <- min(counts[counts > 0])/10
counts <- counts + pseudocount
counts <- counts[c(1:4951, 4985:5017), 25:36]
all_genes <- rownames(counts)

rhos <- propr(t(counts), metric = "rho")

Dendrogram

The figure below shows a dendrogram representation of the hierarchical clustering generated by hclust with average method and at a distance (1 - ρ) of 0.25 (i.e., approximately 75% positive proportionality in expression). A higher cutoff height would yield larger clusters, although there might be genes with low coexpression within them. A lower cutoff height would yield greater proportionality in expression, although the clusters would be smaller. Furthermore, to simplify the analysis, only clusters with 20 or more genes were obtained. A single exception to this rule was the inclusion of a cluster with 19 genes, as it included the genes expressed from GIL16 P1-P2 tandem promoters.

Code 
hc <- hclust(as.dist(1 - rhos@matrix), method = "average")

hc_clusters <- cutree(hc, h = 0.25)
cluster_sizes <- table(hc_clusters)
big_ids <- as.numeric(names(cluster_sizes[cluster_sizes >= 20]))
stable_ids <- c(17, 46, 132, 135, 136, 243, 257, 258, 285, 334, 351, 427)
ids <- sort(c(big_ids, stable_ids))
small_ids <- as.numeric(names(cluster_sizes[cluster_sizes < 20]))
small_ids <- setdiff(small_ids, c(stable_ids, 470))
leaf_order <- hc$order
clusters_in_order <- hc_clusters[leaf_order]
clusters_left_to_right <- rle(clusters_in_order)$values
which_big <- match(ids, clusters_left_to_right)
which_big <- which_big[!is.na(which_big)]

x_pos <- seq_along(leaf_order)
centers <- tapply(x_pos, clusters_in_order, mean)
centers_big <- centers[as.character(ids)]

genes_big <- names(hc_clusters)[hc_clusters %in% ids]
clusters_big <- hc_clusters[hc_clusters %in% ids]

cluster_gene_table <- data.frame(
  Cluster = clusters_big,
  Gene = genes_big,
  stringsAsFactors = FALSE
)

sizes <- cluster_gene_table %>% count(Cluster, name = "Size")
first_appearance <- cluster_gene_table %>% distinct(Cluster) %>% mutate(first_pos = row_number())

map_tbl <- sizes %>%
  left_join(first_appearance, by = "Cluster") %>%
  arrange(Size, first_pos) %>%
  group_by(Size) %>%
  mutate(
    tie_index = row_number(),
    letter = if (n() > 1) num_to_letters(tie_index) else rep("", n()),
    size_lab = sprintf("%03d", Size),
    new_name = paste0("GIL16_C", size_lab, letter)
  ) %>% ungroup()

cluster_to_name <- setNames(map_tbl$new_name, map_tbl$Cluster)

cluster_gene_table <- cluster_gene_table %>%
  mutate(Cluster = cluster_to_name[as.character(Cluster)]) %>%
  dplyr::left_join(
    annotation,
    by = c("Gene" = "Gene_ID")
  )

ids_labels <- unname(cluster_to_name[as.character(ids)])

op <- par(col = "grey", xpd = NA, mar = par("mar") + c(1,0,0,0))
plot(hc, labels = FALSE,
     main = NA,
     sub = NA, xlab = NA, ylab = "Distance (1 - ρ)")
rect.hclust(hc, which = which_big, h = 0.25, border = which_big)

y_min <- par("usr")[3]
text(x = centers_big,
     y = y_min - 0.01 * diff(par("usr")[3:4]),
     labels = ids_labels,
     cex = 0.5,
     srt = 90,
     adj = 1,
     col = "black")

Heatmap

After obtaining the dendrograms, we will represent how similar they are to each other with respect to gene expression patterns. To do this, we will use the distance of all genes in each cluster from the others to obtain an average distance (1 - ρ) and graphically represent the results in an interactive heatmap. As we can see, there is a main subdivision into two branches, among which we could distinguish some superclusters based on distance. For example, GIL16_C289 and GIL16_C061 have a distance (1 - ρ) of 0.2823, i.e., raising the threshold to this value would merge them into a supercluster. The next closest would be GIL16_C025b, which has distances of 0.3133 and 0.2728 to GIL16_C289 and GIL16_C061, respectively. Depending on the enrichment results, we could consider raising the cutoff threshold to obtain separate functions in each cluster, although for the moment we will maintain the previously defined threshold.

Code 
labels_new <- unname(cluster_to_name[as.character(ids)])

members_list <- setNames(
  lapply(ids, function(k) which(hc_clusters == k)),
  labels_new
)

avg_inter <- matrix(0,
                    nrow = length(ids),
                    ncol = length(ids),
                    dimnames = list(labels_new, labels_new))

for (i in seq_len(length(ids))) {
  for (j in i:length(ids)) {
    if (i != j) {
      m <- mean((1 - rhos@matrix)[members_list[[i]], members_list[[j]]])
      avg_inter[i, j] <- m
      avg_inter[j, i] <- m
    }
  }
}

hc_row <- hclust(as.dist(avg_inter), method = "average")
hc_col <- hclust(as.dist(avg_inter), method = "average")

dend_row <- as.dendrogram(hc_row)
dend_col <- as.dendrogram(hc_col)

dend_row_olo <- seriate_dendrogram(dend_row, as.dist(avg_inter), method = "OLO")
dend_col_olo <- seriate_dendrogram(dend_col, as.dist(avg_inter), method = "OLO")

order_row <- order.dendrogram(dend_row_olo)
order_col <- order.dendrogram(dend_col_olo)

order_x <- colnames(avg_inter)[order_col]
order_y <- rownames(avg_inter)[order_row]

heatmaply(
  avg_inter[order_y, order_x, drop = FALSE],
  colors = viridis(n = 256, alpha = 1, begin = 1, end = 0, option = "viridis"),
  distfun_row = function(x) as.dist(x),
  distfun_col = function(x) as.dist(x),
  hclustfun_row = function(d) hclust(d, method = "average"),
  hclustfun_col = function(d) hclust(d, method = "average"),
  seriate = "none",
  symm = TRUE,
  scale = "none",
  label_names = c("Row", "Column", "Distance (1 - ρ)"),
  width = 1000,
  height = 800
)

Clusters composition

The interactive table below displays clusters with 20 or more genes and the genes that comprise them. Above each column is a filter box that allows to filter by cluster, gene name, location, etc. At first glance, we observe that 2207 out of 5023 genes (43.94%) are located in clusters. Also, it can be observed that a large proportion of pBtic235 genes belong to cluster GIL16_C289. Regarding the prophage region (GBJ002_00964 to GBJ002_01009 genes), some genes are in GIL16_C289, although they are more distributed than in the other hierarchical clusterings. Last but not least, GIL16 genes expressed from P1-P2 tandem promoters (plus GIL16_34, expressed from the negative strand) are found in GIL16_C019, while those expressed from P3 promoter are found in GIL16_C031.

Enrichment analysis

As with determining the enrichment of upregulated or downregulated genes, an enrichment analysis was performed according to the COG, KEGG, GO and EC categories to determine if clusters are enriched in any function.

COG

Regarding COG categories, 11 clusters show significant enrichment comprising 9 distinct terms. Among the most notable findings are GIL16_C071, which is enriched in genes related to cell cycle control, cell division, chromosome partitioning (D), and GIL16_C019, which includes 5 genes involved in amino acid transport and metabolism (E).

Code 
cog_results <- cog_enrichment_by_cluster(cluster_gene_table, all_genes)

datatable(cog_results, rownames = FALSE,
  colnames = c("COG", "IN", "OUT", "Genes", "Odds ratio", "p value", "Adjusted p-value", "Cluster"),

  formatRound(columns = "odds.ratio", digits = 2) %>%

KEGG

Regarding KEGG terms, there is a wide variety across the clusters. GIL16_C036b is related to quorum sensing pathways, while GIL16_C027a is related to membrane transport. Regarding replication and repair pathways, we can observe two distinct clusters: GIL16_C289, associated to DNA replication, mismatch repair, homologous recombination and nucleotide excision repair, and GIL16_C050, associated to the last pathway. Interestingly, 17 clusters appears to be enriched in diverse metabolic pathways, which suggests a specialization in gene expression in the different reflected pathways.
