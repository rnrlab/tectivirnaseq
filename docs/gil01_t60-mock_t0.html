Time points 60-mock vs 0 contrast

Author

Eduardo Lozano

Published

November 19, 2026

In order to perform the time 60-mock vs 0 contrast, we established a log₂ fold-change (LFC) threshold of ±0.585. This value reflects an increase or decrease in expression of 50%, depending on whether it is positive or negative, respectively. The default value is 0, but when performing the other contrasts we obtained too many differentially expressed (DE) genes. This violates one of DESeq2’s key assumptions, which is that most genes are not differentially expressed.

Code 
contrast <- results(dds, contrast = c("Time", "60", "0"), lfcThreshold = log2(1.5))
contrast_df <- as.data.frame(contrast)

contrast_df <- contrast_df %>%
  { x <- .; x$Gene_ID <- rownames(x); x } %>%
  left_join(
    annotation %>%
      filter(Gene_ID %in% rownames(contrast_df)) %>%
      dplyr::select(Gene_ID, Gene_symbol, Description, COG, Classification, Association, Type, Subtype, Source),
    by = "Gene_ID"
  ) %>%
  rename(
    Mean_normalized_counts = baseMean,
    LFC = log2FoldChange,
    Adjusted_p_value = padj
  ) %>%
  dplyr::select(
    Gene_ID,
    Gene_symbol,
    Description,
    COG,
    Classification,
    Association,
    Type,
    Subtype,
    Source,
    Mean_normalized_counts,
    LFC,
    Adjusted_p_value
  )

As can be seen in the summary() results, 249 upregulated and 210 downregulated genes were obtained. In addition, 294 genes were discarded due to low counts, probably because they are expressed in inducted samples or in the absence of GIL01. Below is an interactive table where all DE genes can be viewed individually.

MA plot

A MA plot visualizes the relationship between the mean expression and the LFC for each gene. It helps to identify genes that are differentially expressed across conditions, highlighting those with large fold changes relative to their expression level.

Code 
plotMA(contrast, alpha = 0.05, xlab = "Mean of normalized counts", ylab = "LFC")

DE genes

DE genes are defined as those with an adjusted p-value below 0.05. Among them, upregulated genes are extracted as those with a LFC > 0.58, while downregulated genes are defined as those with an LFC < -0.58.

Code 
up_genes <- rownames(subset(contrast, padj < 0.05 & log2FoldChange > log2(1.5) & !is.na(padj)))
down_genes <- rownames(subset(contrast, padj < 0.05 & log2FoldChange < -log2(1.5) & !is.na(padj)))

Volcano plot

A volcano plot displays each gene according to its LFC on the x-axis and the statistical significance (−log₁₀ adjusted p-value) on the y-axis. In this contrast, we found a large number of upregulated and downregulated genes on the chromosome, but on pBtic235 we only found an upregulated gene (GBJ002-DNT_270) and some downregulated genes which encode primarily for tRNA and phage and hypothetical proteins. As we could see in the analog contrast for GBJ002, GBJ002-DNT_270 is the most upregulated pBtic235 gene, so it appears to be more abundant over time regardless of MMC induction and presence of GIL01. Furthermore, as expected, no GIL01 gene is DE, even though GIL01-DNT_01 has a LFC > 1 (adjusted p-value = 0.584). In the absence of further data, it could be interpreted that this gene is involved in the maintenance of lysogeny and/or has an anti-sense interference mechanism of action, as explained by Pavlin et al. (2022).

Code 
volcano_plot(contrast_df)

Enrichment analysis

In this section, we present the results of enrichment analyses based on the COG (Clusters of Orthologous Groups), KEGG (Kyoto Encyclopedia of Genes and Genomes), GO (Gene Ontology) and EC (Enzyme Commission) categories for both upregulated and downregulated genes.

COG

According to COG categories, we only found positive enrichments in energy production and conversion (C), carbohydrate transport and metabolism (G), amino acid transport and metabolism (E) and lipid transport and metabolism (I) by 27, 27, 33 and 15 genes, respectively. As we could see in the GBJ002 analogous contrast, in this case we can observe more enrichments, suggesting that, even in the absence of MMC induction, the presence of GIL01 affects GBJ002 metabolism.

Code 
cog_up <- cog_enrichment(up_genes, all_genes)
cog_down <- cog_enrichment(down_genes, all_genes)

KEGG

According to KEGG categories, we found positive and negative enrichments. In the case of the former, they were all related to metabolism: amino acids, carbohydrates, biosynthesis of secondary metabolites, etc. This was to be expected, since the culture was growing and the metabolism was active. In the case of the latter, it resulted in depletion of other metabolic pathways, such as biosynthesis of other amino acids and nitrogen metabolism.

GO

The Gene Ontology (GO) is organized into three categories: Biological Process (BP), which describes the biological objectives to which gene products contribute; Molecular Function (MF), which refers to the elemental activities of gene products at the molecular level; and Cellular Component (CC), which specifies the locations within the cell where gene products are active.

Enrichment summary

This table contains a summary of the enrichments for each category. The subcategory was used for KEGG and the description for GO. Although you can scroll, I recommend exporting using the Excel button and viewing the table in full screen.

Code

es_down <- enrichment_summary(down_genes, categories = list(cog_down, kegg_down, go_bp_down, go_mf_down, go_cc_down, ec_1_down, ec_2_down, ec_3_down))
es_de <- rbind(es_up, es_down)
rownames(es_de) <- c("UP", "DOWN")
