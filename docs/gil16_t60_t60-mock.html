Time points 60 vs 60-mock contrast

Author

Eduardo Lozano

Published

November 19, 2026

In order to perform the time 60 vs 60-mock contrast, we established a log₂ fold-change (LFC) threshold of ±0.585. This value reflects an increase or decrease in expression of 50%, depending on whether it is positive or negative, respectively. The default value is 0, but when performing the other contrasts we obtained too many differentially expressed (DE) genes. This violates one of DESeq2’s key assumptions, which is that most genes are not differentially expressed.

Code 
contrast <- results(dds, name = "MMC_TRUE_vs_FALSE", lfcThreshold = log2(1.5))
contrast_df <- as.data.frame(contrast)

contrast_df <- contrast_df %>%
  { x <- .; x$Gene_ID <- rownames(x); x } %>%
  left_join(
    annotation %>%
      filter(Gene_ID %in% rownames(contrast_df)) %>%
      dplyr::select(Gene_ID, Gene_symbol, Description, COG, Classification, Association, Type, Subtype, Source),
    by = "Gene_ID"
  ) %>%
  rename(
    Mean_normalized_counts = baseMean,
    LFC = log2FoldChange,
    Adjusted_p_value = padj
  ) %>%
  dplyr::select(
    Gene_ID,
    Gene_symbol,
    Description,
    COG,
    Classification,
    Association,
    Type,
    Subtype,
    Source,
    Mean_normalized_counts,
    LFC,
    Adjusted_p_value
  )

MA plot

A MA plot visualizes the relationship between the mean expression and the LFC for each gene. It helps to identify genes that are differentially expressed across conditions, highlighting those with large fold changes relative to their expression level.

Code 
plotMA(contrast, alpha = 0.05, xlab = "Mean of normalized counts", ylab = "LFC")

DE genes

DE genes are defined as those with an adjusted p-value below 0.05. Among them, upregulated genes are extracted as those with a LFC > 0.58, while downregulated genes are defined as those with an LFC < -0.58.

Code 
up_genes <- rownames(subset(contrast, padj < 0.05 & log2FoldChange > log2(1.5) & !is.na(padj)))
down_genes <- rownames(subset(contrast, padj < 0.05 & log2FoldChange < -log2(1.5) & !is.na(padj)))

Volcano plot

A volcano plot displays each gene according to its LFC on the x-axis and the statistical significance (−log₁₀ adjusted p-value) on the y-axis. In this contrast, we found a large number of upregulated genes on both the chromosome and pBtic235, but much more downregulated genes on the chromosome. Regarding the prophage region, it contains 7 of the 10 most overexpressed genes of the chromosome, the remaining ones being GBJ002_04994 (YolD-like family protein) and DNT 160. Regarding GIL16, almost all genes were upregulated and with LFC between 5.33 and 9.72, being GIL16-DNT_01 the only not DE gene. In the plot, if we select only upregulated GIL16 genes, we can distinguish two main zones: GIL16_01 to GIL16_07 genes, with LFC < 7; and GIL16_10 to GIL16_31 genes (and GIL16_35 and GIL16_36), with LFC > 8. The first region corresponds mainly to the genes of the P1-P2 tandem promoters, while the second corresponds to those of the P3 promoter. As we can see, genes expressed from the P3 promoter are more upregulated than those expressed from the P1-P2 tandem promoters, although in this contrast GIL16_08 and GIL16_35 genes appear to be more associated with the genes of the P3 promoter than with those of the P1-P2 tandem promoters, contrary to what occurred in the previous contrast.

Code 
volcano_plot(contrast_df)

Enrichment analysis

In this section, we present the results of enrichment analyses based on the COG (Clusters of Orthologous Groups), KEGG (Kyoto Encyclopedia of Genes and Genomes), GO (Gene Ontology) and EC (Enzyme Commission) categories for both upregulated and downregulated genes.

COG

According to COG categories, we found positive enrichment in replication, recombination and repair (L), mobilome: prophages, transposons (X), function unknown (S) and nucleotide transport and metabolism (F) and negative enrichment in energy production and conversion (C) and amino acid transport and metabolism (E).

Code

KEGG

According to KEGG categories, we found positive and negative enrichments. In the case of the former, they were mainly related to amino acids and nucleotides metabolism, but also to replication and repair pathways. In the case of the latter, they were associated to translation and diverse metabolic pathways, including some related to carbon fixation, amino acids and secondary metabolites.

GO

The Gene Ontology (GO) is organized into three categories: Biological Process (BP), which describes the biological objectives to which gene products contribute; Molecular Function (MF), which refers to the elemental activities of gene products at the molecular level; and Cellular Component (CC), which specifies the locations within the cell where gene products are active.

EC

The EC classification establishes up to four levels to define enzymes. In this section, the first three were analyzed, achieving statistical significance in all of them. In the first, translocases (7) number was enriched due to 17 upregulated genes, while oxidoreductases (1) and ligases (6) were enriched due to 50 and 24 downregulated genes. In the second, 5.6 level was enriched by 12 upregulated isomerases altering macromolecular conformation genes. Lastly, in the third, 5.6.2 level was positively enriched by 12 out of 39 genes.

ec_1_down <- ec_enrichment(down_genes, all_genes, 1)

Enrichment summary

This table contains a summary of the enrichments for each category. The subcategory was used for KEGG and the description for GO. Although you can scroll, I recommend exporting using the Excel button and viewing the table in full screen.

Code
